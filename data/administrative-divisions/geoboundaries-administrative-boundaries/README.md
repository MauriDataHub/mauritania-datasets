# geoBoundaries — Mauritania administrative boundaries (ADM0–ADM2)

Open administrative boundary polygons for Mauritania from the geoBoundaries project (gbOpen release): country outline (ADM0), regions/wilayas (ADM1, 13 units) and departments/moughataas (ADM2, 57 units).

## Processing

GeoJSON files downloaded unchanged from the geoBoundaries API (gbOpen). `levels.csv` reproduces the API metadata per level.

## Coordinate reference system

WGS 84 (EPSG:4326), as distributed by geoBoundaries.

## Limitations

The ADM1 layer (2015, 13 units) predates the 2014 split of Nouakchott into three wilayas (Nouakchott-Nord, -Ouest, -Sud) and therefore does not match the current 15-wilaya structure; use the OCHA COD-AB dataset for current boundaries. Boundaries are not an authoritative statement on international borders.
