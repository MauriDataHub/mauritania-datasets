# Mauritania - Subnational Administrative Boundaries

Mauritania administrative level 0-2 boundaries (COD-AB) dataset version 03. This dataset is structured into 2 levels: - Admin 1: 15 - Admin 2: 63 Dates associated with this dataset: - 30 October 2025: dataset reviewed for accuracy and completeness - 27 March 2024: valid for use by the humanitarian community - 31 October 2024: last edit to the dataset before publishing - 31 October 2024: boundaries created by the source Quality assured, configured, and published by OCHA Field Information Services (FIS) and HDX. ## Methodology (from the publisher)

Dataset: Adapted from Agence Nationale de la Statistique, de l’Analyse Démographique et Economique (ANSADE) data

## Coordinate reference system

GeoJSON files use WGS 84 (EPSG:4326) longitude/latitude per RFC 7946 unless a `crs` member states otherwise. GeoPackage, shapefile and GeoTIFF files keep the CRS embedded by the publisher.

## Limitations

Several topology errors exist, and are particularly obvious at administrative level 0. These will be fixed shortly.
