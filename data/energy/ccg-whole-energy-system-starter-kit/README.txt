Climate Compatible Growth: Whole Energy System Model Starter Data Kit
-----------------------------------------------------------------------

This data repository contains the following files:

1_SDK_<COUNTRY>.xlsx: Consolidated dataset containing all core data inputs for the energy system model, including techno-economic parameters, demand projections, resource availability, and emission factors.

Calculators_<COUNTRY>.zip: Supplementary material containing all calculator files used to estimate and derive various data points included in the consolidated database. These calculators document intermediate assumptions, methodologies, and calculation steps to enhance transparency and reproducibility.
