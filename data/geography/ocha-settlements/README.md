## Methodology (from the publisher)

The dataset is collected from the NGA website and cleaned and pcoded by OCHA and ITOS.

## Coordinate reference system

GeoJSON files use WGS 84 (EPSG:4326) longitude/latitude per RFC 7946 unless a `crs` member states otherwise. GeoPackage, shapefile and GeoTIFF files keep the CRS embedded by the publisher.

## Limitations

This dataset is not completly cleaning, it remains some villages with variable names and same coordinates (eg. Aicha Dhkhira, Aicha Dkhira, Aicha Edkhera, Aaicha Edjera.....).
