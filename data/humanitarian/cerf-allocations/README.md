# Mauritania - CERF Allocations

This dataset lists project funding allocations from OCHA's Central Emergency Response Fund (CERF) for Mauritania. CERF allocations are made to ensure a rapid response to sudden-onset emergencies or to rapidly deteriorating conditions in an existing emergency and to support humanitarian response activities within an underfunded emergency.
