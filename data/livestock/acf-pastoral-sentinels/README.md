# West and Central Africa - Pastoral Sentinels

Data from pastoral sentinel sites collected as part of the Pastoral Early Warning and Surveillance System (PEWS). These data are freely accessible for humanitarian or research purposes. Any commercial exploitation of this data is prohibited. No compensation can be demanded in exchange for the dissemination of this data. ## Processing

Converted the regional XLSX (`ACF_Pastoral_Sentinels.xlsx`) to CSV keeping only rows where `adm0_name` = 'Mauritania' (0 of 47551 rows). All columns retained; values unchanged.

## Original resources

- ACF_Pastoral_Sentinels (XLSX): https://geosahel.info/MetaDownload/PEWS/Sentinels/ACF_Pastoral_Sentinels.xlsx

## Methodology (from the publisher)

Data collected through questionnaires administered to a network of data collectors. Données collectées par le biais de questionnaires adressés à un réseau de collecteurs de données.
