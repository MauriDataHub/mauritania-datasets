# Harmonised satellite-derived relative wealth estimates - Mauritania (feature panel + RWI surfaces, 2016-2026)

Harmonised satellite-derived relative wealth estimates for Mauritania, one country of a 23-country African dataset spanning 2016-2026. This record contains two linked products: Input &mdash; mauritania_feature_panel.parquet : the per-H3-resolution-9 annual feature panel used to train the model (Earth-observation, climate, connectivity and conflict predictors). Output &mdash; relative-wealth surfaces ( h3_9 / h3_8 / h3_7 / adm3 / adm2 / adm1 ): predicted relative wealth per spatial grain per year, anchored to the DHS asset wealth index. Methods and validation are described in the accompanying Data Descriptor. Released under CC-BY-4.0.
